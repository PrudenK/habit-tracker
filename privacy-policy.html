Política de Privacidad - Habit Tracker

Última actualización: 28 de agosto de 2026

Habit Tracker respeta la privacidad de sus usuarios. La aplicación está diseñada para funcionar sin recopilar ni enviar información personal a servidores externos.

1. Información que recopilamos

Habit Tracker no recopila directamente información personal de los usuarios. La aplicación no requiere la creación de una cuenta ni solicita datos como nombre, dirección de correo electrónico, número de teléfono o contraseña para utilizar sus funciones principales.

Habit Tracker tampoco accede a la ubicación del dispositivo, contactos, cámara, micrófono, mensajes SMS ni llamadas telefónicas.

2. Datos almacenados en el dispositivo

La información que el usuario introduce en la aplicación, incluyendo sus hábitos, objetivos, progresos y demás información relacionada con el uso de la aplicación, se almacena localmente en el dispositivo del usuario.

Estos datos no se envían a nuestros servidores ni se comparten con terceros por parte de Habit Tracker.

3. Copias de seguridad

Habit Tracker permite al usuario crear copias de seguridad de sus datos para poder importarlos posteriormente.

Estas copias de seguridad son creadas y gestionadas por el propio usuario. La aplicación no las envía automáticamente a ningún servidor externo.

4. Compartición de datos

Habit Tracker no vende, alquila ni comparte información personal de los usuarios con terceros.

La aplicación tampoco utiliza los datos almacenados localmente para publicidad personalizada, análisis de comportamiento o seguimiento de usuarios.

5. Servicios y librerías de terceros

La aplicación utiliza determinadas librerías de software de terceros para proporcionar funcionalidades de la aplicación. Estas librerías se utilizan para funciones técnicas y de interfaz y Habit Tracker no las utiliza para recopilar información personal de los usuarios.

6. Conservación y eliminación de datos

Los datos de Habit Tracker almacenados localmente permanecen en el dispositivo del usuario mientras este los conserve.

El usuario puede eliminar sus datos utilizando las funciones de eliminación disponibles en la aplicación cuando correspondan o eliminando los datos locales de la aplicación desde los ajustes del dispositivo.

Las copias de seguridad creadas por el usuario deben eliminarse manualmente por el propio usuario desde la ubicación donde las haya guardado.

7. Seguridad

Al no transmitir Habit Tracker los datos de los hábitos a servidores externos, dichos datos permanecen almacenados localmente en el dispositivo del usuario.

8. Privacidad de menores

Habit Tracker no solicita deliberadamente información personal de menores de edad ni recopila información personal con fines de identificación.

9. Cambios en esta política

Podemos actualizar esta Política de Privacidad cuando sea necesario para reflejar cambios en la aplicación o en sus prácticas de privacidad. Cualquier modificación será publicada en esta página indicando la fecha de la última actualización.
